Game Jam Projects

RainRush — Games for Change Student Game Jam KL @ Indie Jam 2026

High-speed arcade rainforest racer created for Games for Change Student Game Jam Kuala Lumpur at Indie Jam 2026. Players race through a rainforest track, drift through tight corners, charge drift energy, and boost past AI opponents while maintaining control at extreme speeds.

Gameplay Highlights
  • Arcade racing focused on high-speed driving with a 300–500 km/h top speed feel
  • Drift system for handling corners and building drift energy
  • Boost mechanic tied to energy management and aggressive driving
  • AI opponent behaviour tuned using player driving data as reference
  • Spline-based road mesh generation for track creation
  • Custom particle effects for speed, boost, and visual feedback
  • Shader Graph animated materials for stylized environmental and vehicle visuals
  • Terrain and forest-based rainforest map design
  • Custom color grading to shape the overall mood and presentation
  • Thorough playtesting of both player handling and AI racing behaviour

Night Delivery — Beyond Game Jam 2026: BiasBreakers

Horror game project inspired by late-night delivery tension and atmospheric exploration. Players navigate a dark environment, complete deliveries, and uncover unsettling events while progressing through the experience.

Gameplay Highlights
  • Unity ECS-based crowd rendering enabling ~1000 zombies on screen with minimal performance loss
  • Flow-field navigation system for large-scale enemy movement toward the player vehicle
  • LOD-group optimization separating near-interaction zombies from distant simulation agents
  • Physics-based truck controller using Wheel Colliders
  • Close-proximity zombie physics allowing hordes to push and disrupt the vehicle
  • Road network system used for both driving and AI navigation
  • Minimap navigation that calculates shortest paths using weighted road segments
  • Garage upgrade system supporting day/night gameplay variations
  • Reusable traffic systems derived from the driving simulator framework
  • Pause and settings UI with audio control

C++ Projects

Space Shooter — 2D Arcade Game in C++ with Raylib

A 2D arcade space shooter developed in C++ using Raylib. Players pilot a spaceship, dodge incoming meteors, and fire lasers to survive while building a high score. The project demonstrates real-time game loop management, collision handling, sprite-based animation, timed enemy spawning, and audio integration in a simple but polished arcade experience.

Gameplay Highlights
  • Built in C++ using Raylib
  • Player-controlled spaceship movement within screen bounds
  • Laser shooting system with sound effects
  • Randomized meteor spawning with varying speed and direction
  • Collision detection between player, lasers, and meteors
  • Score system based on destroying meteors
  • Animated explosion effects when meteors are hit
  • Background starfield for added visual atmosphere
  • Background music and arcade-style audio feedback
  • Survival-based gameplay loop with game over on collision

SpaceGame — 2D C++ GL2D OpenGL Arcade Shooter

A 2D arcade space shooter developed in C++ using OpenGL through the gl2d rendering library. The player controls a ship in an open arena, aims with the mouse, and shoots enemy ships that spawn around the player. Enemies can also fire back, creating a fast-paced survival gameplay loop focused on movement, aiming, projectile combat, and health management.

Gameplay Highlights
  • Built in C++ with OpenGL-based 2D rendering
  • Mouse-aimed player shooting system
  • Enemy spawning around the player at random positions
  • Enemy AI movement and projectile attacks
  • Bullet collision, damage, and despawn handling
  • Player health system with on-screen UI bar
  • Layered parallax scrolling backgrounds
  • Arcade-style survival combat loop
